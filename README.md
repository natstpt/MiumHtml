# Kru Mium Learning Tools

สื่อการเรียนรู้แบบโต้ตอบสำหรับเด็กประถม พัฒนาโดย **ครูเมียม ปูชิตา** ให้เด็กได้ลองตั้งเวลาและชั่งน้ำหนักด้วยตนเอง ผ่านหน้าปัดที่ลากเข็มได้และภาพประกอบที่เปลี่ยนตามค่าที่เลือก

## ทดลองใช้งาน

เปิดเว็บไซต์ **[Kru Mium Learning Tools](https://natstpt.github.io/kru-mium-learning-tools/)** แล้วเลือกเครื่องมือจากเมนูด้านบน

- [นาฬิกากำหนดเวลา](https://natstpt.github.io/kru-mium-learning-tools/index.html)
- [ตาชั่งผลไม้](https://natstpt.github.io/kru-mium-learning-tools/fish-scale.html)

## ภายในเว็บไซต์

### หน้านาฬิกา

ใช้ฝึกอ่านเวลาและทำความเข้าใจการเดินของเข็มนาฬิกา

- พิมพ์เวลา หรือใช้ปุ่มเวลาแนะนำ: 0:00, 5:00, 8:00, 12:00, 17:00 และ 20:00 น.
- ลากเข็มสั้นหรือเข็มยาวด้วยเมาส์หรือนิ้ว เข็มสั้นจะขยับเพิ่มหนึ่งชั่วโมงเมื่อเข็มยาววนครบ 60 นาที
- แตะภาพพระอาทิตย์หรือพระจันทร์เพื่อสลับกลางวันและกลางคืน โดยเปลี่ยนเวลาไป 12 ชั่วโมง
- สุ่มเวลา ซ่อนหรือแสดงตัวเลข และส่งออกภาพหน้าปัดเป็น PNG

### หน้าตาชั่งผลไม้

ใช้ฝึกอ่านน้ำหนักและเปรียบเทียบหน่วยกิโลกรัมกับกรัม

- กำหนดน้ำหนักได้ตั้งแต่ 0–5 กิโลกรัม โดยพิมพ์ค่า ใช้แถบเลื่อน หรือลากเข็มบนหน้าปัด
- สลับหน่วยระหว่าง kg และ g พร้อมซ่อนหรือแสดงตัวเลขได้
- ภาพผลไม้บนถาดเปลี่ยนจำนวนตามน้ำหนัก โดยประมาณทุก 500 กรัมต่อผลไม้หนึ่งชิ้น เช่น 500 กรัมมี 1 ชิ้น และ 1 กิโลกรัมมี 2 ชิ้น
- สุ่มน้ำหนักและส่งออกภาพตาชั่งเป็น PNG

## การแสดงผลและเทคโนโลยี

- รองรับหน้าจอมือถือ แท็บเล็ต และคอมพิวเตอร์ รวมถึง iPad Pro 11 นิ้วทั้งแนวตั้งและแนวนอน
- สร้างด้วย HTML, CSS, JavaScript และ SVG ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม
- เผยแพร่เว็บไซต์ด้วย GitHub Pages

## โครงสร้างไฟล์

- `index.html` — หน้านาฬิกา
- `fish-scale.html` — หน้าตาชั่งผลไม้
- `navigation.css` — เมนูและรูปแบบการแสดงผลร่วมกัน
- `assets/classroom-banner.webp` — ภาพแบนเนอร์ตกแต่งเว็บไซต์

## เปิดใช้งานบนเครื่อง

ดาวน์โหลดหรือ clone repository แล้วเปิด `index.html` ในเว็บเบราว์เซอร์ได้เลย ทั้งสองหน้าเป็นเว็บแบบ static และไม่มี dependencies ที่ต้องติดตั้ง
